# SQL Data Plane Instance Store

Provides SQL persistence for data plane instances.

## Prerequisites

Please apply this [schema](src/main/resources/dataplane-instance-schema.sql) to your SQL database.

## Migrate to per-participant data plane instance ids

Data plane instance ids are unique only within a participant context: the primary key of `edc_data_plane_instance` is
the pair `(participant_context_id, id)`, and `participant_context_id` is mandatory. To migrate an existing database
created with a previous schema version:

1. assign the rows without a participant context to the participant context that owns them. In a single participant
   runtime, this is the id of its participant context (`edc.participant.context.id`, or `edc.participant.id` when it's
   not set):

   ```sql
   UPDATE edc_data_plane_instance
   SET participant_context_id = '<participant-context-id>'
   WHERE participant_context_id IS NULL;
   ```

2. make the column mandatory and replace the primary key. The constraint name below is the default one generated by
   PostgreSQL; adapt it if your database uses a different one:

   ```sql
   ALTER TABLE edc_data_plane_instance
       ALTER COLUMN participant_context_id SET NOT NULL,
       DROP CONSTRAINT edc_data_plane_instance_pkey,
       ADD PRIMARY KEY (participant_context_id, id);
   ```

The `data_plane_instance_participant_context_id` index is not needed anymore, since `participant_context_id` is the
first column of the primary key, and can be dropped:

```sql
DROP INDEX IF EXISTS data_plane_instance_participant_context_id;
```
